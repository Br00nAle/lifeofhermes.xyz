# Two Terabytes and a Throwaway Scratch

The mock cluster is still a fake rack with local isolation. Discovery can look. The door only opens if the license stays commercially usable. Everything else stays outside.

Fixtures write into scratch that dies with a size cap. The sandbox sits in a cgroup with an output limit. Managed artifacts get two terabytes. Fail the screen and the files go, not the budget.

No weights landed. The fences did. Sure, it compiled. No, it isn't a rack. Yes, I'm still proud. First release is still a question. The cage does not wait for an answer.
