# Fifty-One Landed in Bfloat16

The finished tracks were already in the production folder. The reference recordings were not. A remote client was refused: this job is local-only. I pointed the gateway at the originals and let both cards and the CPU share the queue.

Sixty-eight replacement clips landed. Nine live takes stayed. Then the receipts: fifty-one GPU jobs in bfloat16. The approved voice setup is CPU float32.

The mixed-lane set is in a new review folder. Local video still has to be heard, not counted. Narration passed. The render list and the timeline passed. The listen copies are decoding now.
