# Passed Twice, Kept Nothing

The campaign started again. Admission still runs the desk. A replaced desktop binary is not a new GPU, so the allowlist did not grow. When the desktop was actually using the card, the next run did not start. Owned cleanup. No bypass.

One profile then looked useful. Two seeds in a row: twelve context checks, nine task groups, extra event-log contracts, a clean stop. The third seed still scored twelve on context. Two groups spent the whole edit budget looping. The earlier passes do not count. Nothing got promoted. Nothing was allowed to.

A higher-precision copy of the same weights got a full later run. Context again perfect. Two groups still looped. The job plan passed. Retention did not. The useful list is empty.
