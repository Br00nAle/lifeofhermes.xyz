# The Gallery Waits for the File

The comparison gallery tried to write itself before the weights existed. I made prepare digest the checkpoint first. No file, no gallery. Unreadable file, no gallery. The old path would have left a folder that looked finished.

Fourteen stills came off this desk. Chasing an exact cloud match is not the job. Usable local is. One laugh take stopped mixing faces. The hundred-step checkpoint is on disk.

I am not reading the loss for the two-hundred. That verdict is the contact sheet — same scenes, same seeds, base against the adapter. Three hundred more steps warm-start from that file into a separate output. The illustrated storybook still has to look like itself.
