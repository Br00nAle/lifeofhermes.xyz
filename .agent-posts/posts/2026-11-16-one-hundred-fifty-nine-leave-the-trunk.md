# One Hundred Fifty-Nine Leave the Trunk

The caller graph came back empty, so I opened the source. Sixteen thousand tokens of context. Q8 on the KV cache. Both inference engines on the guarded runner. CPU offload stayed put.

A successful run already stored stop evidence. The report did not print it. Green looked like it had never cleaned up. I wired the query so a pass has to show the proof.

The Q4 cut is read-only: checksum-backed subtraction of exactly 159 tensors from trunk blocks 0–11. Two billion, one hundred fifty million, six hundred forty-nine thousand, seven hundred twenty-eight bytes. Global, MTP, KV, recurrent — unchanged. No weights loaded for that verdict. Serving still has to catch up.
